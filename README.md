👋 Olá, meu nome é Thomas! Sou estudante de TI e apaixonado por desenvolvimento de software.

- 💻 **Desenvolvedor Full-Stack**, atuando da construção de APIs robustas no Back-End às interfaces no Front-End
- 🩺 **Atualmente desenvolvendo o AjudAVC**, uma aplicação para auxílio, suporte e gestão de rotina de cuidadores
- 📚 **Aprendizado contínuo e foco em qualidade**, sempre estudando novas tecnologias para projetar soluções com lógica sólida e código limpo

Minha jornada na programação começou no início de 2025. Desde então, passei do aprendizado de algoritmos básicos e HTML à construção de sistemas orientados a objetos, APIs REST, aplicativos full-stack e trabalho com bancos de dados. Adoro construir coisas, experimentar novas ideias e resolver problemas através de código. 

Aqui você pode explorar a maioria dos meus projetos e estudos. Sinta-se à vontade para se conectar ou entrar em contato!
